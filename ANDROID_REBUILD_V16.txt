ATHENA V16 — UI + WAKE FIX

Fixes:
- Reworked Android main layout to fit small/tall screens without clipping the input or Tools button.
- Uses ADJUST_RESIZE for the keyboard.
- Reduced header footprint and fixed bottom control sizing.
- Always-on wake is enabled by default after microphone permission is granted.
- Prevents repeated foreground-service startup requests from onResume.
- Wake service now tracks successful foreground startup before listening.
- Removed forced offline speech recognition because some phones/providers do not support it reliably.
- “Athena” alone now activates Athena and immediately starts a normal command-listening pass.
- Wake detection also accepts common ASR variants such as “a then a” and phrases containing Athena.
- No intentional Activity close on permission/service errors.
