Athena distribution build

This release is designed around a simple consumer-facing interface:
- Main Android screen has one Tools button; actions live inside Tools.
- PC pairing is automatic on the same Wi-Fi; no address/token entry is needed.
- Android background wake is enabled by default and is restored after reboot when Android permits it.
- User-facing screens avoid model names, API keys, runtime names, IP addresses and pairing tokens.
- The assistant is local-first and does not require a Gemini/OpenAI account for the bundled AI.

Important Android platform note:
A microphone foreground-service notification is required while background listening is active. Android/Honor battery controls can still stop background services; users may need to allow Athena to run in the background for the most reliable wake behaviour.

Accessibility disclosure:
Athena uses Android AccessibilityService only for user-requested, deterministic device actions after the user explicitly enables the service. It does not silently enable accessibility or make autonomous device-control decisions.
