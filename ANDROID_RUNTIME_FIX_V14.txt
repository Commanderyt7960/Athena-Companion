ATHENA V14 ANDROID RUNTIME FIX

Fixed the startup crash reported after granting microphone permission.

Changes:
- Do not start the microphone foreground service from onResume.
- Start it only after RECORD_AUDIO has been explicitly granted.
- Catch SecurityException/IllegalStateException around foreground-service startup.
- Catch foreground-service promotion failures inside AthenaWakeService.
- Safely handle SpeechRecognizer creation failures.
- Request notification permission separately after microphone permission.
- Background wake remains enabled by default once microphone permission is granted.

Android 14+ requires RECORD_AUDIO plus the microphone foreground-service permission/type for this service. The service is started while Athena's activity is visible, satisfying the modern Android while-in-use restriction.
