ATHENA V13.1 - ANDROID BUILD FIXES

This release was rebuilt from V12 after reviewing the source, not just the previous compiler messages.

Fixed:
- Removed the broken multiline Kotlin string in MainActivity.showPermissions().
- Removed fragile regex escapes from the Android wake-word and AI-output cleanup code.
- Removed any invalid isDestroyed lifecycle reference from the wake service.
- Reworked wake-word parsing without regex so Kotlin source cannot fail on invalid escape sequences.
- Prevented onResume() from restarting the background listener while a background wake command is being processed/spoken.
- Background wake service restart timing is guarded against duplicate restarts.
- Removed the BOOT_COMPLETED microphone-service auto-start. Android 14+ does not allow ordinary apps to start a microphone foreground service from BOOT_COMPLETED. The listener must be started while Athena is visible; once started, the foreground service can continue while the user uses other apps.
- Removed the now-unneeded boot receiver and RECEIVE_BOOT_COMPLETED permission.
- Version code 13 / version 3.4.0.

Verification performed here:
- Windows Python companion passes py_compile.
- Kotlin sources were passed through kotlinc parsing; no Kotlin syntax/expecting errors were reported. The standalone compiler cannot resolve Android/AndroidX/MediaPipe classes outside the Android SDK, so the actual Gradle build remains the final verification step.

Important Android platform limitation:
- Android's current foreground-service rules do not permit an ordinary app targeting Android 14+ to start a microphone foreground service from BOOT_COMPLETED. Therefore this release does not pretend to provide impossible silent microphone auto-start after reboot.
