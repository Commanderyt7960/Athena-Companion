# Athena — Store Description

## Short description
A private personal assistant for voice, questions, memory and everyday device control.

## Full description
Meet Athena — a personal assistant designed to feel simple, calm and useful.

Ask questions, talk naturally, save things you want remembered, and use voice commands while you use your phone. Athena can also connect to the Athena companion on Windows so your phone can ask your PC to open apps, control media and perform supported everyday actions.

### Highlights
- Natural conversation
- Voice interaction
- Optional background wake phrase
- Local-first conversation and memory
- Phone-to-PC connection on your home network
- User-controlled Android device actions
- No required Gemini or OpenAI account for the bundled assistant

Athena clearly asks for the permissions needed for features you choose to use. Background listening uses Android's required microphone foreground service notification.
